# Security Policy

## Supported Versions

Only the latest release of Omnia receives active security updates and vulnerability patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or privacy defect in Omnia, please **do not open a public issue**. Instead, please report it through GitHub Private Vulnerability Reporting:

1. Navigate to the **Security** tab of this repository.
2. Under "Reporting", click **Report a vulnerability**.
3. Fill out the advisory form with detailed steps to reproduce, impact assessment, and any potential remediation.

Alternatively, contact the project maintainer directly via GitHub profile contact methods.

### What to Expect

- **Acknowledgment:** Within 48 hours of your report.
- **Assessment:** We will verify the vulnerability and coordinate on remediation.
- **Disclosure:** We adhere to coordinated vulnerability disclosure. We ask that you give us reasonable time to release a patch before disclosing publicly.
